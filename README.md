## 🧠 Contexto do Projeto  

Este projeto foi desenvolvido como parte do **bootcamp “Klabin - Excel e Power BI Dashboards”**, promovido pela **Digital Innovation One (DIO)** em parceria com a **Klabin**.  

O desafio propôs a transformação de um **modelo relacional** em um **Star Schema**, com foco na **análise de dados sobre professores**, seus cursos, departamentos e disciplinas ministradas.  

Os dados utilizados para alimentar o banco foram **gerados por inteligência artificial**, garantindo variedade e coerência com o contexto acadêmico.

---

## 🎯 Objetivo  

O objetivo principal foi construir um **Data Warehouse** voltado à análise de informações relacionadas a professores, estruturando a modelagem em formato **estrela (Star Schema)**.  
Esse formato permite a criação de consultas analíticas mais rápidas, intuitivas e otimizadas para relatórios e dashboards.

---

## 🏗️ Estrutura do Projeto  

O modelo foi desenvolvido com base em uma tabela fato central e dimensões relacionadas que detalham os diferentes aspectos da análise:

- **Fato_Professor:** Contém os indicadores principais, como número de turmas e médias de avaliação.  
- **Dim_Professor:** Informações detalhadas sobre cada professor.  
- **Dim_Departamento:** Dados sobre os departamentos associados.  
- **Dim_Curso:** Cursos ministrados e suas cargas horárias.  
- **Dim_Disciplina:** Disciplinas oferecidas e suas respectivas cargas horárias.  
- **Dim_Tempo:** Dimensão de tempo que permite análises temporais (ano, semestre, data de oferta etc.).

## 📈 Análises Realizadas  

A partir dos dados modelados, foi possível realizar diferentes tipos de consultas e análises, como:

- Professores com o maior número de turmas ministradas;  
- Média de avaliação por departamento e curso;  
- Evolução das avaliações ao longo dos semestres;  
- Comparativos entre carga horária e desempenho docente.  

Essas análises permitem identificar padrões de desempenho, planejar melhor a alocação de docentes e entender a evolução da qualidade de ensino ao longo do tempo.

O modelo resultante permite análises rápidas e de fácil visualização, com base em uma estrutura otimizada para tomada de decisão.
